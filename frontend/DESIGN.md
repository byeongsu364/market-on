# Market-On · DESIGN.md

> 상태: **[제안]** · **2026-11-26 바꿈** (지시서 [030](../docs/tasks/030-frontend-integration.md))
> 바꾼 이유: 기획서의 한 흐름(지도에서 찾기 → 가기 → 찍기 → 판단)으로 화면 52개 시안을 만들면서 디자인 시스템을 새로 정했어요. 올리브·피치 팔레트와 Wanted Sans·SUIT·Geist 조합, "데스크톱은 가운데 480px 앱 프레임" 규칙을 이 문서로 바꿨어요. 팀 승인은 **[확인 필요]**.
> 규칙 전문: 디자인 시스템 README(https://claude.ai/artifact/L1V5Jh6ykC828Qkox5KdTx). 토큰 값: [`docs/Design Tokens.Md`](../docs/Design%20Tokens.Md), 코드 `src/styles/tokens.css`.

## 1. 사이트 소개
- 전통시장 현장에서 "이걸 살까"를 근거와 함께 보여 주는 모바일 웹(PWA). 지도에서 시장과 점포를 찾고, 찍어서 품목·기준시세·확인 포인트를 보고, **소비자가 직접 판단**해요.
- 보는 사람: 시장에 온 손님(한 손에 장바구니), 상인, 시장 관리자, 외국인 방문객(다국어).

## 2. 원칙
- **흰 바탕, 검은 글자.** 색을 내는 것은 품목 그림과 지도 핀뿐.
- **주요 버튼은 검정 하나.** 한 화면에 하나(찍기, 둘러보기, 길 안내, 결과 보기). 나머지는 테두리 없는 옅은 면 또는 밑줄 글자.
- **상자를 줄인다.** 목록은 카드로 싸지 않고 구분선으로 나눠요. 묶어야 할 때만 옅은 면.
- **주황은 켜진 것에만.** 가격 눈금의 켜진 칸, 마감세일 점, 선택된 점포 면.
- **판정 색을 쓰지 않는다.** 초록=좋음, 빨강=나쁨 금지. 가격 차이는 ▲▼ + 숫자.
- **숫자 아래에는 항상 출처.** 가격·시세·지식 바로 아래 13px 출처와 조사일.

## 3. 글꼴
- Pretendard Variable 한 가족(`public/fonts/PretendardVariable.woff2`, `@font-face`). 한글·영문·숫자 모두. 점포 번호와 코드만 mono.
- 제목 600, 본문 400, 가격 숫자만 700 + `tabular-nums`. 제목과 숫자는 음수 자간.
- 한글은 `word-break: keep-all`.
- 크기: 결과 결론 30px, 화면 제목 26px, 묶음 제목 19px, 본문 16px, 보조 14px, 출처 13px, 라벨 11px. 가격 40px / 24px.

## 4. 색
- 컴포넌트는 변수만 씀(HEX 직접 사용 금지). 예전 변수 이름(`--color-bg` 등)은 그대로 두고 값만 새 시스템으로 바꿨어요.
- 지도 핀 여섯 색: 채소·과일 `--pin-produce`, 건어물·젓갈 `--pin-dried`, 수산 `--pin-seafood`, 반찬 `--pin-side`, 정육 `--pin-meat`, 떡 `--pin-ricecake`. 핀 안에는 카테고리 아이콘(색만으로 구분하지 않음).
- 판단 카드와 점포 QR 면은 `surface-dark`.

## 5. 크기와 틀
- 1024px 미만: 앱처럼 한 단, 본문 최대 480px 가운데, 좌우 여백 20px, 하단 탭(지도·찍기·장보기, 가운데 찍기만 검정 면 버튼). 내 정보는 지도 검색창 오른쪽 둥근 버튼.
- 1024px 이상: 상단 머리말(로고, 지도·장보기·상인·시장, 검색창, 언어, 로그인, 사진으로 확인하기). 지도 화면은 왼쪽 패널 420~460px + 오른쪽 지도, 그 밖은 최대 1140px.
- 위아래 안전 영역: `viewport-fit=cover` + `env(safe-area-inset-*)`.
- 간격 4px 단위(4·8·12·16·20·24·32·48·96).
- 터치 영역 44px 이상. 칩과 작은 버튼은 보이는 높이 38px, 터치 영역 44px. 큰 버튼 54px, 중간 48px.

## 6. 모서리·그림자·움직임
- 작은 버튼 10px, 입력창·중간 버튼 12px, 큰 버튼 14px, 묶음 면·카드 20px, 바텀시트 위 24px. 칩·지도 이름표만 완전 둥글게. 버튼을 알약 모양으로 만들지 않음.
- 그림자는 둘뿐: 지도 위에 뜬 것 `shadow-soft`, 바텀시트 `shadow-sheet`. 흰 화면 안에서는 그림자 없음.
- 움직임은 바텀시트가 올라오는 240ms와 버튼 누름 scale 0.97 둘. `prefers-reduced-motion`이면 즉시.

## 7. 화면 구성 규칙
- 지도 홈: 검색창(지도 위) → 지도 → 바텀시트(점포·마감세일·제철과 시세 탭) → 하단 탭.
- 시장 안 지도: 실제 지도(네이버) 위에 시장 경계 2px, 바깥은 흰 면 66%. 키가 없는 mock·테스트에서는 약도("미리보기 지도"). 점포에 좌표가 없으면 평면도(`MiniMap`).
- 품목 검색: 파는 점포만 핀, 나머지는 9px 회색 점. 선택 점포는 큰 핀 + 이름·가격 말풍선.
- 결과: 결론 한 줄 → 가격 눈금 → 현장 가격과 기준시세 표 → 최근 시세 → 확인 포인트 → 물어보기 → 판매 점포.
- 가격 결론 문구는 코드가 고름(`utils/priceBand.ts`). 신선도는 판정하지 않고 "확인 4개 중 3개"처럼 손님이 한 체크만 셈. 판단 카드 하단은 "신선도는 직접 확인했어요".
- 공공데이터 상호명에는 출처, 추정한 위치·취급 품목에는 "업종 기준 · 상인 확인 전", "배치는 예시", "핀 위치는 예시" 꼬리표.
- 데모 데이터의 점포 이름은 "점포 A-01"처럼. 화면의 이름·숫자는 데이터에서만 가져옴.

## 9. 하지 말 것
"신선", "추천 구매", 등급, 별점, "사지 마세요" / 이모지 아이콘 / 그라데이션 띠(랜딩·포스터 머리 제외) / 유리 블러 / 지어낸 후기·수치 / 정보를 가운뎃점으로 길게 잇기(팀이 정한 꼬리표만 예외).

## 10. 접근성
- WCAG 2.2 AA: 글자 대비 4.5:1(작은 회색 글자 포함), 포커스 링 2px `ink`를 2px 띄워.
- 실제 `button`·`a`·`input`+`label`, 아이콘 버튼은 `aria-label`, 지도 핀은 버튼(이름에 카테고리·마감세일·선택 여부).
- 가격 변화는 기호 + 숫자 + 화면 읽기 문장. `lang` 속성을 현재 언어로.
