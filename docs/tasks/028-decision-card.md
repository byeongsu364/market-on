# 작업 지시서 028 · [G1·G2] 구매 판단 카드 — 저장·공유

- 담당: Codex · 지시: Claude · 2026-11-26 · 승인: 병수 ("판단 카드 작업 진행하자")
- 기획: `docs/CONTEXT.md` — 시연 장면 "찍고 → 보고 → **알리고(판단 카드)** → 묻고 → 쌓인다", "소비자가 만든 판단 카드가 **가게 홍보물**이 된다", 공유로 확산
- 원칙: `CLAUDE.md` — **AI는 판정하지 않음**. 카드는 "살 만해요/신선해요" 같은 결론을 쓰지 않고, **손님이 직접 확인한 것과 출처 있는 숫자**만 담음
- 기존: 결과 화면(`Result.tsx`) — `Checklist`(체크박스 있지만 상태 저장 안 함), `PriceCompare`(기준시세·±%·품종), 판매 점포·"어느 가게예요?" 선택, 사진(확인 화면에서 찍은 것), `qrcode` 패키지(포스터에서 사용 중), 폰트 Wanted Sans·SUIT, 토큰 색
- 범위: `frontend/` 위주 + 백엔드 없음(카드는 브라우저에서 만듦). **패키지 추가 금지** (Canvas 2D로 직접 그림). 끝나면 `npm run format`

## 1. 카드 내용 (위에서 아래로)
| 영역 | 내용 | 없으면 |
|---|---|---|
| 머리 | Market-On 로고 글자 · 시장 이름 · 날짜(서울) | — |
| 사진 | 손님이 찍은 사진(정사각 크롭) | 직접 입력이면 품목 이름 큰 글자 면 (회색 면, 가짜 사진 금지) |
| 품목 | 품목 이름 · 품종(골랐으면) | — |
| **내가 확인한 것** | 확인 포인트 중 **손님이 체크한 항목만** ✓ 표시 + "4개 중 3개 확인" | 하나도 안 했으면 "확인 포인트 4개" 목록만 (✓ 없이) |
| 가격 | 현장 가격(입력/가격표) · 기준시세 · **±%** ("기준시세보다 12% 낮아요" — 사실 문장만) | 현장 가격 없으면 기준시세만 |
| 점포 | 고른 점포 이름 ("어느 가게예요?"에서 고른 것) + **QR → `/s/<storeId>`** | 점포 없으면 QR → `/?market=<시장>` (시장 입구 포스터와 같은 링크) |
| 출처 | "aT 기간별 소매가격 · 2026-11-25 조사", 확인 포인트 출처(농사로) 한 줄 | — |
| 바닥 | "Market-On은 판정하지 않아요 · 확인은 직접 했어요" | — |
- 금지: 판정·구매 권유·과장 문구, 실제보다 정확해 보이는 표현("최저가" 등), 손님 위치·기기 정보
- 사진은 **기기 안에서만** 카드로 합성 (서버로 다시 보내지 않음)

## 2. 만들기 (`utils/decisionCard.ts`, 순수 함수 + Canvas)
- 1080×1350 PNG (세로 4:5, SNS 피드 비율). `document.fonts.ready` 후 그림, 폰트 Wanted Sans(제목)·SUIT(본문)
- 색은 **CSS 토큰을 읽어서** (`getComputedStyle`) — 라이트 테마 값 고정 사용(공유 이미지는 어디서나 같게). HEX 하드코딩 금지
- 긴 텍스트 줄바꿈 함수(글자 폭 측정), 최대 줄 수 넘으면 "…"
- 카드 데이터 만들기(`buildCardData(result 화면 상태)`)와 그리기(`drawCard(canvas, data)`)를 분리 → 데이터 부분은 테스트로 검증

## 3. 화면
- 확인 포인트 체크 상태를 결과 화면 상태로 올림 (`Checklist`가 `checked`/`onToggle` 받음, 품목 바뀌면 초기화)
- 결과 화면 하단(판매 점포 목록 아래, "파는 점포 보기" 고정 버튼 위)에 **[판단 카드 만들기]**
- 누르면 바텀시트(기존 `Sheet`): 카드 미리보기(이미지) + **[공유하기]**(`navigator.share({files})`, 지원 안 되면 숨김) + **[이미지 저장]**(다운로드 `market-on-<품목>-<날짜>.png`) + 안내 "사진은 이 기기에서만 카드로 만들어요"
- 미리보기 만드는 동안 로딩, 실패하면 ErrorBox
- 접근성: 미리보기 `img`에 alt = 카드 내용 요약 문장

## 4. 테스트 (vitest)
- `buildCardData`: 체크한 것만 ✓ / 하나도 없을 때 / 현장 가격 없을 때 / 품종 / 점포 있음 → `/s/` 링크, 없음 → `/?market=` / 직접 입력(사진 없음) / 금지 문구가 카드 문장에 없음
- 줄바꿈 함수(측정 함수 모킹)
- 화면: 버튼 → 시트 열림, share 지원·미지원 분기, 다운로드 파일 이름, 품목 바뀌면 체크 초기화
- Canvas는 jsdom에 없으니 `drawCard`는 호출 여부·인자만 확인 (그림 자체는 Claude가 브라우저로 확인)
- 기존 테스트 유지
