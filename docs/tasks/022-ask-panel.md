## 1. 위치 · 흐름
- 결과 화면 **확인 포인트 바로 아래**에 "물어보기" 섹션 (판매 점포 목록보다 위)
- **질문 칩 4개**: `고르는 법`(select) · `보관`(store) · `손질`(prep) · `제철`(season) → `POST /ask {intent, item_id, market_id}`
- **자유 질문 칸**: placeholder "예: 냉동해도 돼요?" · 200자 제한 · [묻기] → `POST /ask {question, item_id, market_id}` (품목은 결과 화면 품목으로 고정해서 보냄 → `need_item` 안 나옴)
- 답 카드는 **최신이 위**, 최대 3개 유지 (같은 칩을 다시 누르면 새로 묻지 않고 기존 카드로 스크롤)

## 2. 답 카드 (`components/domain/AskAnswer.tsx`)
| kind | 표시 |
|---|---|
| `answer` | 질문(칩 이름 또는 입력한 문장) · 답 문장 · **출처 목록**(제목 · 발행처, url 있으면 새 창 링크) · 작은 글씨 "근거 자료에서만 답해요" · 답한 모델 작은 표시(`gemma4:e4b` → "Gemma", `openai:*` → "GPT", 캐시면 "저장된 답") |
| `no_evidence` | 서버 문장 그대로 ("이 품목의 보관 자료가 아직 없어요") + 다른 칩 안내 |
| `price` | "기준시세 ○○원 / 1단" 한 줄 + 위 가격 비교 섹션으로 이동 링크 |
| `where` | "이 시장에서 N곳이 팔아요" + 판매 점포 섹션으로 이동 링크 |
| `out_of_scope` | "이 품목의 고르는 법·보관·손질·제철을 물어볼 수 있어요" |
- 출처 중 **검수 전 자료**(아래 3장 `draft: true`)는 출처 옆에 작은 "검수 전" 표시 (muted 토큰)
- 대기: 답이 보통 5~15초 → 카드 자리에 로딩 + "근거 자료를 찾고 있어요" (`aria-live="polite"`), 묻는 동안 칩·버튼 비활성
- 오류: 503 → "지금은 답변을 찾을 수 없어요. 잠시 뒤 다시 물어봐 주세요" + [다시] / 429 → "질문이 많아요. 잠시 뒤에 다시 물어봐 주세요" / 그 외 기존 `ErrorBox`
- 문구는 i18n 키로 (ko만 채움, 다른 언어는 기존 방식대로 ko 대체)
