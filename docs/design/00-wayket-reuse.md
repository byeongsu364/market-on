## 3. 쓰지 않을 것
- `웹서버/`, `학습준비/`, `학습결과/`의 YOLO 모델·학습 노트북
- OSRM 도로 거리·시장 추천(`스크립트/road_distance_*`, `exp2_*`, `Wayket_B_시장추천_*`): Market-On은 시장 **안**에서 쓰는 서비스라 필요 없어요
- `웹서버/.env`: 키는 Market-On에서 새로 발급하거나 따로 옮기고, 파일째 복사하지 않아요

## 4. 빈 곳 (새로 만들어야 함)
- **채소·수산·축산 KAMIS 코드가 없어요.** Wayket은 과일 15종만 다뤘어요. 시연 품목인 **대파(채소류 200)** 등은 코드를 새로 찾아야 해요.
- 등급 코드가 품목마다 달라요 (대부분 04, 포도·샤인머스캣 24, 감귤 노지·시설 13). 채소도 품목별로 확인이 필요해요.
- 2026-10 기준으로 가격이 비어 있던 품종(사과 후지, 감귤, 딸기, 단감 등)은 제철이 되면 다시 나올 수 있어요. 대회 직전에 가용성을 다시 확인해요.
