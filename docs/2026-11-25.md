### 점포별 가격 조작을 줄이는 장치 (P-3)
기기당 최신 1건만 셈 · 혼자 튀는 값(가운데 값의 ±30% 밖) 제외 · 7일 지나면 숨김 · 오늘 값이 아니면 흐리게 · 상인 확인은 손님 값과 따로 표시

### 개인정보
- 손님은 가입 없음. 기기마다 무작위 ID를 만들고, 서버에는 **비밀값을 섞은 해시만** 저장 (`DEVICE_HASH_SALT`)
- 요청·방문 수는 하루·기기당 1번만 세고, **5명 미만이면 숫자를 숨김** ("5명 미만")
- 입점 신청 연락처는 **시장 공식 연락처만** 받음 (개인 휴대폰 말고 시장 사무실·상인회 대표 번호)

### 검수 (Claude가 실제 서버·DB·Gemma로 직접 확인)
- 테스트: **백엔드 299개, 프론트 57개 모두 통과**
- 로컬 DB `marketon`: 마이그레이션 **0008~0012** 적용
- 브라우저(휴대폰 폭 390px)로 확인한 장면
  - 사과 사진(가격표 "3개 5,000원") → 사과 인식 + 가격 채움 → 기준시세 대비 ▲8% → 판매 점포 목록
  - 가격표 없는 단감 사진 → 묻지 않고 결과로, 제보 저장 안 함
  - 직접 입력 대파 2,500원 → ▲17%, 확인 포인트 3개
  - 사진 인식이 안 될 때 → "이름으로 찾아 주세요" + 직접 입력
  - 상인 가입 → 시장 관리자 승인 → 상인 화면 열림
  - 요청 → `/join` 신청(근처에서 연 사람 8명 · 요청 6명) → 운영자 승인 → 시장 열림
- 검수 중 고친 버그
  - 점포를 고르면 같은 가격이 시장 단위·점포 단위로 **두 번 저장**되던 문제 → 한 건으로 갱신
  - 직접 입력 가격(수량 없음)이 점포 가격 계산에서 **모두 빠지던** 문제 → 1단위로 계산
  - `/join` 관리 주체 칩이 모두 선택된 것처럼 보이던 문제
