## 2. aT 가격 API (공통 형식)

aT API 5개는 요청·응답 형식이 같다.

| 항목 | 값 |
|---|---|
| 승인 | 개발계정 자동승인, 24개월 |
| 트래픽 | 하루 10,000건 (개발계정) |
| 라이선스 | 이용허락범위 제한 없음 |
| 명세·코드표 | 각 페이지 참고문서 zip |

| API | Endpoint | 용도 | 특징 |
|---|---|---|---|
| 기간별 소매가격 (15156065) | `B552845/periodRetail/price` | **A7 주력** | **소매만**, 시장(조사처)별 |
| 일별 도·소매 가격 (15156057) | `B552845/perDay/price` | A4·A7 | 도매+소매, 시장별 |
| 지역별 도·소매 가격 (15156062) | `B552845/perRegion/price` | B3 | 지역 평균·최저·최고 (`cond[sgg_cd::EQ]` 필수) |
| 최근일자 도·소매가격 (15156063) | `B552845/recent/price` | 홈 화면 | 1일·1주·1개월·1년 전 가격 함께, 날짜 조건 없음 |
| 가격 추이 (15156069) | `B552845/priceSequel/info` | 시세 추이 | 1~4주 전 평균, 날짜는 `cond[exmn_ymd::EQ]` |

주소 앞부분은 모두 `https://apis.data.go.kr/`

### 요청 파라미터

| 파라미터 | 필수 | 예시 | 비고 |
|---|---|---|---|
| `serviceKey` | O | | Decoding 키 권장 (Encoding 키 쓰면 이중 인코딩 주의) |
| `pageNo` / `numOfRows` | O | 1 / 1000 | numOfRows 최대 1000 |
| `cond[exmn_ymd::GTE]` / `cond[exmn_ymd::LTE]` | O | 20261120 | **YYYYMMDD만 동작** (`2026-11-20`은 0건) |
| `cond[ctgry_cd::EQ]` | O | 200 | 부류: 100 식량 / 200 채소 / 300 특용 / 400 과일 / 600 수산 |
| `cond[item_cd::EQ]` | O | 246 | 품목코드. **빼면 0건** |
| `cond[vrty_cd::EQ]` | | 00 | 품종 (예: 파 246 → 00 대파 / 02 쪽파) |
| `cond[se_cd::EQ]` | | 01 | 01 소매 / 02 중도매 |
| `cond[grd_cd::EQ]` | | 04 | 등급. 소매는 상품(04)만 사실상 조사됨 |
| `cond[mrkt_cd::EQ]` | | 0110212 | 특정 시장만 (0110212 = 서울 경동) |
| `returnType` | O | JSON | |

### 응답 형식 (실제)

```json
{"response": {
  "header": {"resultCode": "0", "resultMsg": "정상"},
  "body": {"items": {"item": [
    {"exmn_ymd": "20261120", "se_cd": "01", "se_nm": "소매",
     "item_cd": "246", "item_nm": "파", "vrty_cd": "00", "vrty_nm": "대파",
     "grd_cd": "04", "grd_nm": "상품", "sgg_nm": "서울",
     "mrkt_cd": "0110212", "mrkt_nm": "경동",
     "unit": "kg", "unit_sz": "1",
     "exmn_dd_prc": "2500", "exmn_dd_cnvs_prc": "2500"}
  ]}, "totalCount": 50}
}}
```

- 응답 전체가 `response`로 한 번 감싸져 있음.
- 에러는 다른 형식: `{"OpenAPI_ServiceResponse": {"cmmMsgHeader": {"errMsg": "..."}}}`

### 시장 구분 규칙

| 조건 | 분류 |
|---|---|
| `se_cd == "02"` (가락도매, 엄궁도매 등) | 도매시장 |
| `mrkt_nm`이 `-유통`으로 끝남 (B-유통, C-유통 …) | 대형유통 |
| 그 외 (경동, 부전, 칠성, 현대, 양동, 역전, 신정, 지동, 중앙, 육거리, 남부, 죽도, 상남, 동문) | 전통시장 |
| `복조리` (0110213) | 확인 필요 (코드가 경동 0110212 옆 → 전통시장 가능성) |

- **시장코드로 나누면 틀림.** 순천 역전(전통시장)이 `0360402`라 대형유통 코드처럼 보임. 이름 규칙으로 나눌 것.
- KAMIS 웹 안내문의 전통시장 목록은 오래됨 (영등포는 2021년 폐지, 칠성·죽도는 목록에 없음).

### 실제 데이터 (2026-11-20, 상품, 1kg)

| 품종 | 전통시장 평균 | 대형유통 평균 | 차이 |
|---|---|---|---|
| 대파 | 2,576원 (15곳) | 2,451원 (34곳) | 전통시장 약 5% 비쌈 |
| 쪽파 | 3,824원 (14곳) | 4,059원 (29곳) | 전통시장 약 6% 저렴 |

- 경동시장(0110212): 대파 2,500원 / 쪽파 3,550원
- 서울 지역 평균(15156062): 대파 2,410원 (최저 1,300 · 최고 3,980)
- 전국 최근일자(15156063): 대파 2,489원 (1일 전 2,465 · 1개월 전 2,791 · 1년 전 3,252)
- 가격 추이(15156069): 대파 1~4주 전 2,297 / 2,597 / 2,274 / 2,784원

### aT 주의사항

1. **초당 호출 제한이 빡빡함.** 연달아 호출하면 `LIMITED_NUMBER_OF_SERVICE_REQUESTS_PER_SECOND_EXCEEDS_ERROR`. 몇십 초 후 풀림. → 호출 간격 1초 이상, 하루 1회 배치로 DB 저장.
2. **주말·공휴일은 조사 없음.** 최근 평일 데이터를 써야 함.
3. **조사 단위가 품목마다 다름.** 시금치 100g, 오이 10개, 사과 10개, 고등어 1손 등 → 가격표 비교하려면 품목별 단위 환산표 필요.
4. **품종 구분 필수.** 상추(적/청), 풋고추(꽈리/청양/오이맛), 사과(후지/홍로/시나노골드).
5. **축산물(500)은 미확인.** 2022년부터 축산물 소매가격은 축산물품질평가원으로 이관됨.
6. **가공식품(두부·김치·콩나물)은 조회 범위에서 못 찾음.**
7. 실파는 KAMIS 조사 품목에 없음.
8. 소매 조사지역은 22개 도시 (2026-09 김해 폐지).

## 4. 기상청 단기예보 (15084084)

- 파라미터: `base_date`(yyyyMMdd), `base_time`(0200·0500·0800·1100·1400·1700·2000·2300), `nx`, `ny`, `dataType=JSON`, `numOfRows`, `pageNo`

- F5에 쓸 항목: `TMP`(기온), `SKY`(하늘), `PTY`(강수형태), `POP`(강수확률)

## 7. 식품안전나라 레시피 DB (COOKRCP01)

- 키: 식품안전나라에서 별도 발급 → `FOODSAFETY_KEY`
- 호출 형식 (키가 주소 안에 들어감):
  `http://openapi.foodsafetykorea.go.kr/api/{키}/COOKRCP01/json/{시작}/{끝}/RCP_PARTS_DTLS=대파`
- 검색 조건: `RCP_NM`(메뉴명), `RCP_PARTS_DTLS`(재료), `RCP_PAT2`(요리종류), `CHNG_DT`(변경일)
- **http 주소라 브라우저(화면 코드)에서 부르면 막힘 → 서버에서만 호출**
- 확인 결과: 재료에 대파 포함 레시피 **172개** (예: 부추 콩가루 찜, 된장국)
- 응답 항목: 메뉴명, 요리종류, 조리방법, 재료(`RCP_PARTS_DTLS`), 만드는 법 1~20단계와 사진, 열량·영양, 저감 조리법 TIP
- 레시피는 자주 바뀌지 않으므로 페이지의 CSV 다운로드로 한 번에 받아 두는 방법도 가능

## 8. 네이버 지도 (Maps · Web Dynamic Map)

- 신청처: 네이버 클라우드 플랫폼 콘솔 → Services → Application Services → Maps → Application
- Application 이름 `market-on`, API는 **Dynamic Map만** 선택 (Static Map·Directions·Geocoding은 안 씀, 필요해지면 추가)
- Web 서비스 URL: `http://localhost:5173`, `http://localhost:5174`, `http://127.0.0.1:5173`. 이 주소에서 연 화면에서만 지도가 뜬다. 배포 주소(https 도메인)는 정해지면 추가하고, 서버 IP로 임시 테스트했다면 도메인으로 바꾼 뒤 지운다.
- Android 앱 패키지·iOS Bundle ID: 비움 (설치형 앱이 아니라 모바일 웹이라 필요 없음)
- 키: [인증 정보]의 Client ID → `NAVER_MAP_CLIENT_ID`, Client Secret → `NAVER_MAP_CLIENT_SECRET` (`.env`에만, 팀원에게는 1:1로)
- 지도 스크립트: `https://oapi.map.naver.com/openapi/v3/maps.js?ncpKeyId={Client ID}` (예전 이름 `ncpClientId`는 바뀜)
- 요금: 대표 계정 1개에 한해 Dynamic Map 월 600만 건 무료. 대표 계정이 아니면 과금되므로 콘솔에서 대표 계정 여부 확인, [한도 및 알림 설정]으로 상한 설정
- 확인 결과 (11/26): `http://localhost:5173`에서 경동시장 좌표(37.5803, 127.0393) 중심 지도와 마커 표시 성공, 인증 실패 없음
- 아직 앱 화면에는 연결 안 됨 (지도 연결은 별도 작업)

## 9. 확인 방법

- 위 내용은 개인 확인용 스크립트와 브라우저 호출로 실제 확인했다. **서약서(사전 제작 결과물 금지)에 따라 그 스크립트는 저장소에 올리지 않고**, 수집 코드는 대회 현장에서 새로 작성한다.

